界线之内

可步行探索的微缩职场，与五章原创视觉小说交织。玩家输入昵称、选择主角，在六个场景间移动，调查物件、找同事交谈，并作出十三次属于自己的回答。

探索循环

移动 → 看见附近人物与物件 → 收集线索 → 走近同事 → 进入视觉小说 → 作出选择 → 回到地图。共有 18 个剧情相遇节点与 14 项物件调查，答错可以重试，不替玩家选定剧情答案。

五个自由场景通过门口连通：营业厅、资料室、玻璃会议室、休息花园、雨后街角。猫爪书签、花园橘猫与旧路灯是三个可收集彩蛋；集齐后开启风铃天台。

镜头与操作

默认使用 Three.js 第三人称透视镜头，平滑跟随主角，保持局部视野；可切换原来的俯视镜头。手机滑动旋转、双指缩放，电脑拖动旋转、滚轮缩放。画面内的视角与复位按钮提供快速调整，C 切换视角、R 复位。移动方向会跟随镜头，远处、离屏或背后的标记隐藏。方向键或 WASD 移动、Shift 快走、E 互动，也可点地面或标记。场景地图可以自动导航，人物实际走过连接通道。

手机菜单与任务详情默认收起，操作按钮半透明悬浮在地图内。手机横置后自动适配横屏，对话与选项调整位置。减少动态效果时镜头直接跟随，无额外环境循环动画。WebGL2 不可用时提供可移动的轻量地图。

剧情、存档与纪念

完整保留五章、155 个剧情节点、13 个关键选择、三种结局、五项成就、自定义主角和左右发言高亮。通关后可保存带昵称、主角、徽章、结局及原完成日期的 1200×1600 PNG 纪念图。

自动存档与三个手动槽保存剧情、场景、人物位置、镜头模式及角度、线索和彩蛋。章节回放不覆盖主线。旧版本存档保持当前对白并迁移探索状态。本机保存失败与多标签页冲突都有明确恢复入口。

部署与编辑

运行只需要 index.html，无需后端、构建或运行时 CDN。所有插画与 Three.js 本地内嵌，保留原有 iframe 沙盒及 CSP。MIT 许可见 THREE-LICENSE.txt。

源码位于 source/。修改后执行 npm ci、npm run build，将生成的 dist/index.html 替换包根入口。执行 npm test 验证完整剧情、存档与下载桥接、各场景路线和彩蛋解锁。详细操作见 README.txt。

内容来源

主题取材于用户提供的《兴业银行员工行为十三条禁令（2021年9月修订）》海报。第十二条仅采用清楚可辨认的“严禁在空白纸张上加盖本行印章”摘录。人物、情境、线索与彩蛋均为虚构；游戏不办理真实业务、不采集客户资料。成就用于游戏内纪念，不构成正式合规认证或员工评价。
