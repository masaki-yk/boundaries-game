# 界线之内

合规主题视觉小说。五章剧情、十三个关键选择、三种完整结局，以及五项成就和专属通关纪念图。

## 游玩

打开 `index.html`，或访问发布后的 GitHub Pages 网站。输入主角昵称，选择人物形象，在关键场景选择回答。读完结局最后一句对白后，可获得成就并下载通关纪念 PNG。

全部图片、剧情、样式和逻辑已内嵌于 `index.html`。无需安装依赖、构建或配置后端。

存档与成就保存在当前设备的浏览器中。换浏览器、设备或网址不会自动同步存档。

## GitHub Pages

仓库 Settings → Pages → Deploy from a branch，选择 main 分支和 /(root)，保存。

本目录含三个文件：

- `index.html`：完整游戏。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。
- `README.md`：说明。

`index.html` 与已交付的完整静态包 v2 保持字节一致，保留内外 CSP 和 iframe 的 allow-scripts 沙盒。

## 内容来源

题材基于用户提供的《兴业银行员工行为十三条禁令（2021年9月修订）》海报。人物、对白和情境均为虚构，用于创意合规宣传。成就是游戏内完成与收集纪念。
