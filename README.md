# 界线之内

合规主题探索游戏与视觉小说。操控主角穿过营业厅、资料室、玻璃会议室、休息花园和雨后街角，调查线索、与人物交谈，完成五章剧情、十三个关键选择和三种完整结局。收集三处隐藏彩蛋后，可以进入风铃天台。

## 游玩

[开始游戏](https://masaki-yk.github.io/boundaries-game/)

输入昵称，选择主角形象。电脑使用 WASD 或方向键移动，Shift 加速，E 互动；也可点击地面或目标前往。手机使用场景内的半透明方向键与互动按钮，支持横屏。点击悬浮菜单可以展开记录、图鉴、成就、存档、章节和设置。

镜头跟随主角，地图可选择目的地并自动通过相连的门。遇到人物后进入对话模式；完成剧情可获得游戏成就和个人通关纪念 PNG。竖屏对话人物贴住场景底部，当前说话人物高亮。

存档、探索进度和成就保存在当前浏览器中。换浏览器、设备或网址不会自动同步。

游戏区域关闭长按选中、原生弹出菜单和立绘拖拽，方向键可持续按住移动。昵称输入仍可编辑、粘贴，通关纪念 PNG 仍可长按保存。

## 静态部署

`index.html` 已内嵌全部图片、剧情、样式、Three.js 和游戏逻辑，无需后端、运行时 CDN 或额外下载。GitHub Pages 从 main 分支的根目录发布；`.nojekyll` 保留。

保留现有内外 CSP 和 iframe 的 allow-scripts 沙盒。Three.js 的 MIT 许可见 `THREE-LICENSE.txt`，完整功能及制作说明见 `制作说明.html`。

题材基于用户提供的《兴业银行员工行为十三条禁令（2021年9月修订）》海报。人物、对白和情境均为虚构，用于创意合规宣传。成就是游戏内完成与收集纪念。
